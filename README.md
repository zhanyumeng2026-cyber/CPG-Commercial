# 詹雨萌 · Yumeng Zhan — Brand Management / CBD Portfolio

中英双语个人主页（快消外企品牌管理 / CBD 方向）。纯静态页面，无需构建。

## 目录
- `index.html` 主页（右上角 中 / EN 切换，或在链接后加 `?lang=en` 直接打开英文版）
- `img/` 页面图片与微信二维码
- `resume/` 简历与作品集 PDF（点击后在浏览器 PDF 阅读器中预览、下载）

## 部署到 GitHub Pages
1. 在 GitHub 新建仓库（例如 `ZhanYumeng-FMCG`），设为 Public。
2. 把本文件夹里的**全部内容**（含隐藏文件 `.nojekyll`）上传到仓库根目录。
3. 进入 Settings → Pages → Build and deployment：Source 选 `Deploy from a branch`，Branch 选 `main` / `(root)`，保存。
4. 1–2 分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。

> 两个 PDF 均小于 GitHub 网页上传的 25MB 单文件上限；如之后替换为更大的文件，请改用 git 命令行推送（单文件上限 100MB）。
